---
description: 把一天的原始照片與短片掛上展覽牆（匯入、看圖、寫草稿、提出排版）
argument-hint: <YYYY-MM-DD> [城市] [地點]
---

把 $ARGUMENTS 這一天掛上展覽牆。依序執行，每一步有問題就停下來回報：

1. **確認素材**：列出 `raw/<日期>/` 的檔案數量與類型。資料夾不存在或是空的，就請 Viking 放入原始檔（HEIC / MOV，不要截圖或轉傳過的檔案），然後停止。
2. **匯入**：執行 `npm run ingest -- <日期>`，有城市、地點就加上 `--city`、`--place`。回報新增的編號、讀不到時刻的檔案、拍攝日期不符的警告。
3. **看圖**：用 Read 逐一查看新展品的圖片（短片看 poster）。記下：畫面內容、是否有路人正臉、是否模糊或有遮擋。
4. **寫草稿**：在每個新展品檔填 `title` 與 `note`。
   - 只寫看得到的事實（地點、物件、天氣、光線），不寫感受與評價。
   - 不確定地點或名稱時，寫「待確認」，不要猜。
   - 保持 `draft: true`。
5. **提出排版**：依拍攝時間與主題，把 `unsorted` 欄拆成正式欄位的建議（每欄 1–3 件、欄寬 200–420、直幅用窄欄、全景用寬欄），每欄可加一張 `text` 文字卡，並放一個 `slot` 心得欄位。**先用表格列出建議給 Viking 看，得到同意後才寫入 days 檔**。
6. **驗證**：`npm run build`，再用瀏覽器看一次這天的版面（桌機與手機寬度）。
7. **回報**：用表格列出每件展品（編號、時刻、標題、疑慮），以及需要 Viking 決定的事：路人正臉、模糊照片、待確認的名稱、心得欄位。
