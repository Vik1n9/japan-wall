做一次分享前檢查。**這個指令只檢查和回報，不修改任何檔案。**

1. 執行 `npm run check`，列出所有錯誤與提醒。
2. 列出 `draft: true` 的展品，以及 `time: null` 的展品。
3. 用 Read 查看每張展品圖片與短片 poster，標出：
   - 可辨識的路人正臉（Viking 與同行者以外的人）
   - 車牌、門牌、住宿房號、票券條碼等可識別資訊
4. 檢查 `src/content/days/` 是否還有 `status: pending` 的佔位日，或 `unsorted: true` 的欄。
5. 執行 `npm run build`，確認成功；用瀏覽器在桌機（1440px）與手機（400px）寬度各看一次，並打開一張展品說明卡。
6. 用一張表格回報：項目、狀態（通過／需處理）、證據（檔名或指令輸出）、建議做法。最後一句話說明：目前是否適合公開分享。
