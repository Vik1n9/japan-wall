# 大阪行：旅行展覽牆

把 2026 年 10 月五天的大阪之旅做成一面**博物館式的年代展覽牆**。照片與短片像展品一樣掛在牆上，每件都有編號和說明卡；同行親友可以補上自己的照片，也能在牆上留言、掛繪馬。

網址：https://osaka2026.voriens.dev

## 特色

### 一面可以走完的展覽牆

- **城市是年代、一天是刻度**：參考實體年代牆的語彙。每座城市一段，大號日期加城市名；基準線隨行程逐段升高，每天一個刻度，標出日期、星期、DAY n、地點與展品數。
- **展品編號與說明卡**：照片與短片編號為 `JP-<天>-<序號>`。點一下打開說明卡，顯示標題、地點、時刻、媒材與說明；方向鍵逐件瀏覽，Esc 關閉。
- **時刻只來自拍攝資料**：讀得到 metadata 才寫時刻，讀不到就標「時刻待補」。日期採日本式 30 小時制，凌晨 0:00–5:59 算前一天（例如 24:10）。
- **說明只寫看得到的事實**：心情與感想留給 Viking 自己寫。

### 瀏覽方式

- 橫向捲動的牆面，滑鼠滾輪會轉成橫捲，右上角也有 ← → 按鈕。
- 牆下方的**平面圖**分段標出序幕、各城市與結尾，紅框是目前位置，可以點或拖曳跳轉。
- **閱讀模式**改成直向排列，適合手機，選擇會記住。
- 短片靜音循環，只在畫面看得到時播放；系統設定「減少動態效果」時不自動播放。
- 支援淺色與深色模式，手機寬度 400px 也能完整瀏覽。

### 浮世繪風格的大阪

- 狂放筆勢的書法標題、序幕的天守閣與紅色直書布條、牆頂軌道燈的光暈。
- 牆腳是大阪城石垣，上方一道瓦屋簷。
- 每天一組出血的背景拼貼：DAY 1 長榮客機、DAY 2 環球影城地球儀、DAY 3 勝尾寺達摩、DAY 4 大阪城、DAY 5 臨空城摩天輪。
- **屋簷趣事帶**：六隻擬人貓代表同行六人，每天在屋簷上演出當天的一件趣事。
- 這些都是裝飾，不算展品，也不加說明文字。

### 親友一起補完

- **帳號由管理員發放**，不開放註冊；第一次登入必須先改密碼。
- **親友照片**：上傳後立刻公開，掛在指定那天最右邊的「親友照片」欄。
- **留言與繪馬**：可以在展品說明卡裡留言、回覆；繪馬像展品一樣掛在當天的「繪馬掛所」。
- **內容審核**：管理員可以檢視並刪除任何公開中的照片與投稿。
- **前後台分開兩個網域**：公開的展覽牆完全沒有登入入口，編輯與管理只在後台網域。

### 隱私

- 公開的照片與短片一律移除 metadata（含 GPS），短片去除音軌；親友上傳的照片在瀏覽器與伺服器各剝一次。
- 路人的臉以模糊處理；同行友人的正臉都已取得同意。
- 建置前自動檢查，帶 metadata 的檔案或 HEIC／MOV 原檔進不了公開目錄。
- 牆上只顯示顯示名稱與署名，不露出登入帳號。

## 技術

- [Astro](https://astro.build) 靜態建置。內容全是 YAML 資料檔：展品資訊（`exhibits/`）與排版（`days/`）分開管理。
- Cloudflare Workers：前台 `osaka2026` 與後台 `osaka2026-kura` 兩個 Worker，共用 D1 資料庫與 R2 儲存。
- 素材處理：sharp 轉 WebP、ffmpeg 剪輯短片（防手震、電影級運鏡速度）。裝飾圖以本機圖片模型（FLUX.2 Klein、Qwen-Image）生成與風格化。

## 快速開始

```sh
npm install                 # 需要 Node ≥ 22.12
brew install ffmpeg         # 匯入短片用；只看網站可以不裝
npm run dev                 # http://localhost:4321
```

- **新增一天**：把原始檔放進 `raw/<日期>/`，在 Claude Code 執行 `/add-day <日期> <城市>`。
- **本機跑後台**：`npm run build`、`npm run db:setup:local`、`npm run admin:create -- <帳號> --local`，再 `npm run dev:api`（http://localhost:8787，含 `/edit`、`/admin`）。
- 完整指令表見 `CLAUDE.md`。

## 部署

Cloudflare 帳號的第一次設定（建 D1、R2、管理員）見 `TODO.md`。設定好之後，任何一台機器都能重新部署：

1. `git clone https://github.com/Vik1n9/japan-wall.git`、`npm install`。部署只需要版控裡的檔案；`raw/` 原始檔只有重新剪輯或匯入時才需要。
2. `npx --yes wrangler@4 whoami`，確認登入的是 Viking 的 Cloudflare 帳號；沒登入就先 `npx --yes wrangler@4 login`。
3. `npm run deploy:back`（後台 kura.osaka2026.voriens.dev），再 `npm run deploy`（前台 osaka2026.voriens.dev）。
4. 用瀏覽器在桌機與手機寬度各看一次，開一張說明卡、播一支短片。

## 專案結構

```
japan-wall/
├── src/
│   ├── content/site/trip.yaml   標題、起始日、布條、署名、裝飾素材、圖片來源
│   ├── content/days/            每天一檔：城市、地點、欄位排版、背景、趣事帶
│   ├── content/exhibits/        每件展品一檔
│   ├── components/ lib/ pages/  展覽牆（index）、編輯模式（edit）、後台管理（admin）
│   ├── scripts/ styles/
├── public/media/<日期>/         處理後的照片、短片與封面
├── public/art/                  書法標題、石垣、屋簷、天守閣、每日背景、趣事帶
├── worker/                      前台與後台 Worker、D1 資料表
├── scripts/                     匯入、隱私檢查、建管理員、後台測試
├── prototype/                   v3 單檔原型，外觀與互動的基準
├── raw/                         原始照片與短片（不進版控）
└── docs/                        設計規格與決策紀錄
```

## 文件

- `CLAUDE.md`：Claude Code 的工作規則與指令表。
